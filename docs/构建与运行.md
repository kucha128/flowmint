# 构建与运行

## 前置环境

- **Rust**（stable，用 rustup 安装）+ Windows 上的 MSVC（VS 2022，rustc 自动发现）。
- **Node.js** 与 npm（桌面前端与 SDK 用）。
- 桌面应用运行需 **WebView2 Runtime**（Windows 11 一般已内置）。
- 若拉取依赖慢或本机走代理：设置 `http_proxy` / `https_proxy` 环境变量后再执行 cargo/npm。

## Rust（核心库 + CLI）

```powershell
cargo build --workspace      # 构建全部 crate 与 CLI
cargo test  --workspace      # 运行测试
cargo run -p flowmint-cli -- <子命令>   # 运行 CLI（也可直接用 target\debug\flowmint.exe）
```

CLI 用法见 [使用指南](使用指南.md)。

## 桌面应用（apps/desktop）

首次安装前端依赖：

```powershell
cd apps\desktop
npm install
```

### 出独立可双击的 exe（发布/日常使用）

```powershell
cd apps\desktop
npm run tauri build -- --no-bundle
```

产物：`apps\desktop\src-tauri\target\release\flowmint-studio.exe`，**双击即用，不依赖任何服务器**。

> ⚠️ **重要**：出独立 exe 必须用 `tauri build`。**不要用 `cargo build`**——那样 Tauri 会当成开发模式，
> exe 启动后去连开发服务器 `localhost:5173`，导致白屏（"localhost 拒绝连接"）。

### 开发模式（热重载）

```powershell
cd apps\desktop
npm run tauri dev
```

会自动起 Vite 开发服务器并打开窗口，改前端代码即时刷新（终端需保持开着）。

前端类型检查：

```powershell
cd apps\desktop
npx tsc --noEmit
```

## 多语言 SDK（sdks/）

各语言 SDK 都是 `crates/ffi` 编出的 `flowmint` 动态库的薄绑定。先构建动态库：

```powershell
cargo build -p flowmint-ffi --release   # 产出 target/release/flowmint.dll
```

各语言的构建/运行与验证见 [多语言 SDK 开发](SDK开发.md)。

## 关于抓取外网

FlowMint 代理目前**直连目标服务**（尚未实现上游代理转发）。因此运行 FlowMint 的机器本身要能直连目标；
若本机无直连外网（例如仅通过某个本地代理上网），则只能抓 **localhost** 的服务。想立刻试通，可先起一个本地
HTTP 服务当目标，再让客户端走 FlowMint 代理访问它。
