# 目录结构与子项目

FlowMint 是一个 **Rust workspace（多 crate）+ Tauri 桌面应用 + 多语言 SDK** 的组合项目。
按职责划分为若干子项目，互不越界，通过 `crates/model` 定义的公共数据契约协作。

## 顶层结构

```text
flowmint/
├── crates/            # Rust 库（核心能力，按职责拆分）
│   ├── model/         # 公共数据契约：事件模型、Flow、Rule IR、ID、时钟、错误
│   ├── storage/       # SQLite 索引 + 内容寻址 chunk 存储
│   ├── tls/           # 每 profile CA、按需签发 leaf、MITM 的 rustls 配置
│   ├── proxy-http/    # 显式 HTTP 代理 + CONNECT 隧道 + HTTPS MITM + WebSocket 帧捕获
│   ├── rules/         # Rule IR 执行器（匹配、动作、前后 diff）
│   ├── engine/        # 抓包生命周期、实时广播、查询/回放/导出（串联各 crate）
│   ├── api/           # 本地 REST 只读 API（loopback + token）
│   ├── mcp/           # 只读 MCP 工具 + stdio 服务器 + 脱敏
│   └── ffi/           # 稳定 C ABI 核心，编成 flowmint 动态库供多语言绑定
├── apps/
│   ├── cli/           # 命令行工具 flowmint
│   └── desktop/       # Tauri 2 桌面分析器（React 前端 + Rust 后端）
├── sdks/              # 多语言 SDK（C ABI 薄绑定，回调式嵌入抓包 + 拦截改包）
│   └── python/ cpp/ c/ csharp/ java/ go/ e/(易语言)
├── examples/          # 规则示例
└── docs/              # 中文项目文档（本目录）
```

## 各子项目职责

### 核心库 `crates/`

| Crate | 职责 | 依赖要点 |
|---|---|---|
| `model` | 所有组件共享的数据契约：`NetworkEvent`、`Flow`、`Rule`/`Action`/`PatchOp`、ID、`Clock`、错误。**其它 crate 都依赖它，它不依赖任何内部 crate。** | 仅 serde/uuid 等 |
| `storage` | SQLite 存元数据索引；正文与二进制以 SHA-256 内容寻址存为 chunk。 | rusqlite |
| `tls` | 每个 profile 独立 CA（rcgen），按 CONNECT 目标主机按需签发 leaf；提供 MITM 用的 rustls 服务端/客户端配置。 | rcgen, rustls |
| `proxy-http` | 抓包适配器：显式 HTTP/1.1 代理、CONNECT 隧道（仅记元数据）、可选 HTTPS MITM（解密捕获）、WebSocket 帧捕获；支持**上游代理链**（出站再转发给指定 host:port）；`decode` 模块按 `Content-Encoding` 解压响应体（gzip/deflate/br/zstd）；`procinfo` 模块（Windows）按源端口反查发起进程（PID/进程名）。通过 `FlowSink` 把结果交给上层。 | tls, tokio, flate2, brotli, zstd |
| `rules` | Rule IR 执行器：匹配 + 动作（redact/json_patch/respond/delay/tag）+ 结构化前后 diff。GUI/SDK/CLI 共用同一份语义。 | model |
| `engine` | 顶层门面：管理抓包生命周期与 profile CA、实时广播 flow、查询/回放规则/导出 HAR。桌面应用与 CLI 都嵌入它。 | storage, tls, proxy-http, rules |
| `api` | 本地 REST 只读模型（`/flows`、`/captures` 等），loopback + 每次启动随机 bearer token。面向脚本/外部工具。 | engine |
| `mcp` | 面向 AI 的只读工具（检索/比较/读取），stdio JSON-RPC 服务器，强制脱敏、返回 evidence id。 | engine, rules |
| `ffi` | 稳定 C ABI 核心：把抓包引擎 + 回调以 C 接口暴露（编成 `flowmint` 动态库），供各语言 SDK 薄绑定复用同一份实现。 | proxy-http, tls, model |

### 应用 `apps/`

- **`cli`**（二进制名 `flowmint`）：**无界面 / CI / 自动化伴生工具**，覆盖 `capture` / `flow` / `rule` / `cert` / `export` / `mcp` / `api`。定位于桌面（要 GUI）和 SDK（要写宿主代码）覆盖不到的场景：headless 抓包、CI 里校验/回放规则、以 MCP/REST 暴露数据。
  代码组织：`cli.rs` 定义 clap 命令，`commands/` 下每个命令一个模块，`main.rs` 只做解析与分发。
- **`desktop`**：Tauri 2 桌面 MITM 分析器（对标 Fiddler/Charles）。
  - `src-tauri/`：Rust 后端，内嵌 `engine`，暴露命令并把实时 flow 以事件推给前端。
  - `src/`：React + TypeScript 前端。`components/`（Toolbar / SessionList / Inspector）、`lib/`（`api.ts` 后端封装、`format.ts` 展示辅助），`App.tsx` 只管状态与布局。

### SDK `sdks/`

**多语言抓包绑定（回调式嵌入）**：`python/ cpp/ c/ csharp/ java/ go/ e/(易语言)`，都是 `crates/ffi` 编出的 `flowmint` 动态库的薄绑定——建实例、绑回调、启动，在**观察回调**里看流量、在**拦截回调**里改包（改 Body/状态/头或丢弃）。Python/C++ 有可运行的改包 demo。详见 [多语言 SDK 开发](SDK开发.md)。

### 其它

- **`examples/`**：`rewrite-profile.flowmint.yaml` 等规则示例。
- **`docs/`**：见 [根 README 的文档导航](../README.md)。

## 数据流（简图）

```text
客户端 → proxy-http（可选 MITM 解密）→ FlowSink
                                          ├→ storage（落盘）
                                          └→ engine 广播 → 桌面 UI 实时刷新
engine ──查询/回放/导出──→ CLI / 桌面 / api / mcp
crates/ffi（flowmint 动态库）──→ 各语言 SDK（Python/C++/C/C#/Java/Go/易语言）
```
