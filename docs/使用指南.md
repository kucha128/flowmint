# 使用指南

FlowMint 有两种用法：**桌面图形应用**（推荐，直观）和**命令行 CLI**（适合脚本/CI）。
两者共用同一个引擎与数据目录。构建方式见 [构建与运行](构建与运行.md)。

> 使用前提：仅对**你有权观测与修改**的流量使用。MITM 默认关闭，且需要客户端显式信任 FlowMint 的 CA。

---

## 一、桌面应用（图形界面）

出独立 exe 并运行（详见 [构建与运行](构建与运行.md)）：

```powershell
cd apps\desktop
npm install                       # 首次
npm run tauri build -- --no-bundle
# 双击 apps\desktop\src-tauri\target\release\flowmint-studio.exe
```

界面布局（对标 Fiddler）：顶部**菜单栏**（文件/捕获/工具/帮助）+ 精简**工具栏**（开始抓包、断点、构造器、安装证书、导出 HAR、清空），中部左右分栏（会话列表 / 检查器），底部**状态栏**（左下角是系统代理开关，右侧显示抓包状态与条数）。端口、MITM、上游代理等配置都在 **工具 → 设置** 里。

界面操作：

1. **工具 → 设置 → HTTPS 解密** 里勾 **解密 HTTPS（MITM）**，并点 **安装 CA 证书到本机**（把 CA 装进当前用户根存储，浏览器才信任）。MITM / 不校验上游 / 上游代理这些**随时可改**，抓包中改会自动重启代理即时生效。
   - **各平台装证书**（对标 Fiddler）：抓包开始后，用浏览器打开 `http://<本机IP>:<端口>/`（如 `http://192.168.1.10:8888/`）即是证书下载页。页面提供两种格式下载（`.crt` 给 Windows/macOS/Android，`.cer` 给 iOS）并内置 **Windows / macOS / Android / iOS 分平台安装引导**。
     - iOS 装完还需在 设置 → 通用 → 关于本机 → 证书信任设置 里**打开完全信任**；证书叶子有效期已控制在 398 天内以满足 Apple 要求。
     - Android 7+ 起，用户安装的 CA 默认只有浏览器等信任，**多数 App 不信任用户证书**（系统限制）。
2. 顶部工具栏点 **▶ 开始抓包**（默认端口 8888，可在设置里改）。
3. 左下角 **系统代理** 开关：点一下立即把 Windows 系统代理指向本工具（再点关闭；停止抓包时也会自动关闭）。旁边还显示**证书**是否已安装。没开系统代理时，手动把客户端 HTTP 代理指向 `127.0.0.1:8888`。
4. 流量**实时**出现在左侧会话列表，多列显示 方法 / 状态 / **协议(HTTP/HTTPS/WS/WSS 一眼区分)** / 主机 / URL / 类型 / **大小** / **进程**（本机发起连接的进程名，Windows 下按源端口反查）；列表宽度可拖动，右键任意一条有**复制 URL / 复制 cURL / 复制响应体 / 重发 / 导出此主机 HAR / 从列表移除**。
5. 点任意一条，右侧检查器有 概览 / 请求 / 响应 / 原始 / Hex / TLS 标签（WebSocket 流是「帧」时间线）。响应体会按 `Content-Encoding` **自动解压**（gzip/br/deflate/zstd）显示文本；**图片响应内联预览**。
6. 检查器右上角 **↻ 重放** 用当前请求填充**构造器**（改 method/URL/头/Body 后重新发送）；**复制 cURL** 复制等价命令。**构造器/重放发出的请求也会记入会话列表**（归属「手动请求/重放」capture），可继续检查、再重放。
7. **工具 → 设置**：代理端口、**上游代理（host:port，形成代理链）**、默认 MITM / 不校验上游。**帮助 → 关于** 查看软件信息。

> 一键解密 HTTPS 的完整流程：勾 MITM → 点安装证书 → 勾系统代理 → 开始抓包 → 浏览器访问 HTTPS 即为明文。
>
> **首次使用（证书自动生成）**：FlowMint 的 CA **在你本机首次用到时自动生成**（存于 `<exe目录>/data/ca/`），每台机器**各不相同、私钥仅本地保留**。所以拉取项目/下载 release 后**无需任何预置证书**——第一次点「安装证书」或开 MITM 抓包即生成你自己的 CA，随后在本机信任它即可。切勿把 `data/ca/`（含私钥）外传或提交。
>
> **代理链**：在「设置」里填上游代理后，FlowMint 会把出站流量（明文 HTTP 用绝对形式请求、HTTPS 用 CONNECT）再转发给它——适合前置科学上网代理或串接另一抓包工具。

## 二、命令行 CLI（无界面 / CI / 自动化）

CLI 定位于**没有图形界面**的场景：服务器/headless 抓包、在 CI 里校验与回放规则、以 MCP/REST 把数据喂给 AI 或外部脚本——桌面（要 GUI）和 SDK（要写宿主代码）覆盖不到这些。交互式改包、重放、系统代理等仍走桌面版。

编译后二进制为 `target\debug\flowmint.exe`（或 `cargo run -p flowmint-cli -- ...`）。
所有命令都有全局参数 `--data <目录>` 指定数据目录（默认当前目录下的 `data`）。

### 抓包 → 检索 → 导出

```powershell
# 启动显式 HTTP 代理抓包（仅 loopback）
flowmint --data mydata capture start --port 8888
# 经上游代理转发（代理链）：--upstream host:port
flowmint --data mydata capture start --port 8888 --upstream 127.0.0.1:10809

# 让客户端走该代理
curl.exe -x http://127.0.0.1:8888 http://目标/路径

# 检索、查看、导出
flowmint --data mydata flow search --host 目标
flowmint --data mydata flow show <flow_id>
flowmint --data mydata export har --out capture.har
```

### 抓 HTTPS（MITM）

```powershell
# 1) 导出并信任 CA（仅在你有权测试的设备上信任）
flowmint --data mydata cert export --out flowmint-ca.pem

# 2) 开启 MITM 抓包
flowmint --data mydata capture start --port 8888 --mitm

# 3) 客户端信任该 CA。curl 示例（Windows 上加 --ssl-no-revoke）：
curl.exe --ssl-no-revoke -x http://127.0.0.1:8888 --cacert flowmint-ca.pem https://目标/路径
```

测试自签名上游可加 `--insecure-upstream`（仅测试用）。

### 规则离线回放

```powershell
# 在已捕获的某条 flow 上离线回放规则，看前后 diff
flowmint --data mydata rule validate --rule examples\rewrite-profile.flowmint.yaml
flowmint --data mydata rule test --rule examples\rewrite-profile.flowmint.yaml --flow <flow_id>
```

### 多语言抓包 SDK

在你自己的程序里嵌入抓包引擎（回调式嵌入）。见 [多语言 SDK 开发](SDK开发.md)。

### AI 接口 / REST API

```powershell
flowmint --data mydata mcp serve      # 只读 MCP（stdio JSON-RPC），供 AI 客户端使用
flowmint --data mydata api serve       # 本地 REST 只读 API（loopback + 随机 token）
```

## 数据与配置存储（可移植）

- **桌面应用**：抓包数据和配置都放在**程序所在目录**，不污染系统其它位置——
  - `<exe目录>/data/index.sqlite`：flow/事件索引；`<exe目录>/data/chunks/`：Body 等内容寻址存储；`<exe目录>/data/ca/`：MITM CA（含私钥，勿外传）。
  - `<exe目录>/flowmint.config.json`：界面设置（端口/MITM/不校验上游/上游代理），下次启动自动恢复。
  - 直接拷走整个目录即可迁移；删除 `data/` 即清空全部抓包数据。
- **清空存储**：菜单 **文件 → 清空存储（删除磁盘数据）** 会真正删库+chunk；「清空列表（仅界面）」只清当前视图、不动磁盘。
- **CLI**：数据目录由 `--data <目录>` 指定（默认当前目录下的 `data`）。

## 常见问题

- **列表为空 / 找不到 flow**：确认抓包和检索用**同一个 `--data` 目录**，且抓完再查。
- **抓不到外网站点**：本机需能直连目标；无直连外网时只能抓 localhost（见 [构建与运行](构建与运行.md)）。
- **桌面应用白屏**：一定是用了 `cargo build` 而非 `tauri build`，见 [构建与运行](构建与运行.md)。
- **curl 报证书错**：Windows 上 MITM 时加 `--ssl-no-revoke --cacert <ca.pem>`。
